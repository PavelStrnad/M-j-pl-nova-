MŮJ PLÁN – PUSH NOTIFIKACE

1) Firebase: Project settings → Cloud Messaging → Web Push certificates → Generate key pair.
2) Do index.html je už vložen veřejný VAPID key. Private key nikam neposílej.
3) Firebase → Authentication: Google musí být Enabled.
4) Firebase → Firestore Database: databáze musí být vytvořená a pravidla publikovaná.
5) Ve Firebase je potřeba zapnout billing/Blaze pro Cloud Functions. Doporučuji nastavit budget alerts.
6) Na PC v kořenu projektu spusť: npm install -g firebase-tools ; firebase login ; firebase deploy --only functions,firestore
7) iPhone: aplikaci přidej na plochu, přihlas Google, klikni 🔔 Upozornění a povol oznámení.
8) U úkolu vyber připomenutí (5/10/15/30/60 min předem). Funkce kontroluje připomínky každou minutu.
