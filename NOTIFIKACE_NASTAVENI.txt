MŮJ PLÁN – PUSH NOTIFIKACE

1) Ve Firebase otevři Project settings → Cloud Messaging → Web Push certificates.
2) Klikni Generate key pair. Zkopíruj PUBLIC VAPID KEY. Soukromý klíč nikam neposílej.
3) Ve frontendovém index.html nahraď VAPID_PUBLIC_KEY_HERE tímto veřejným klíčem.
4) Na PC v kořenu této složky spusť:
   npm install -g firebase-tools
   firebase login
   firebase deploy --only functions,firestore
5) Firebase Cloud Functions + plánované funkce vyžadují Blaze billing. Nastav si v Google Cloud/Firebase rozpočet a upozornění na náklady.
6) Na iPhonu otevři webovou aplikaci PŘIDANOU NA PLOCHU, přihlas Google a klepni na 🔔 Upozornění. Povol oznámení.
7) Při vytvoření úkolu vyber Připomenout: 5/10/15/30/60 min předem.

Poznámka: samotná webová push notifikace na iPhonu funguje pro Home Screen web apps v iOS/iPadOS 16.4+.
